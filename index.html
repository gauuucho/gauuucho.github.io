Framework
360scouting centre back model

A centre back tested against a better side

A full live-coded viewing scored against six defined centre back competencies rather than a general impression. Every judgement in the report traces back to a timestamped action and the actions are published alongside the conclusions so a coach can disagree with me and check.

  • 55 logged actions, each coded to a competency and a pitch zone
  • Defensive action map, duel map and distribution arrows, built in Python
  • Competency breakdown with the evidence behind each score
  • Clip reel grouped by competency, not by chronology
  • Game state split, because his job changed once Paide went behind

This is a single cup tie against a stronger opponent, so it is a sample and it is labelled as one. Routine build-up distribution is under-represented and the report says so rather than filling the gap with adjectives.
